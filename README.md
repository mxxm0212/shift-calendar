# 排班日历 + 飞书提醒

上10天休4天的倒班排班日历工具，支持创建计划并在截止前通过飞书机器人推送到手机。

## 快速开始

```bash
# 1. 安装依赖
cd server && npm install

# 2. 启动服务
npm start

# 3. 打开浏览器
# http://localhost:3456
```

## 设置排班

1. 点击右上角 ⚙️ 设置
2. 填写「排班参考起始日」：选择一个你进班的周一
3. 系统自动推算所有日期的工作/休息状态

## 设置飞书提醒

1. 打开飞书，创建一个群聊（可以只有你自己）
2. 群设置 → 群机器人 → 添加自定义机器人
3. 复制 Webhook URL
4. 粘贴到设置页面的「飞书机器人 Webhook URL」
5. 保存后，计划到期时会自动通过飞书推送提醒到手机

## 键盘快捷键

| 键 | 功能 |
|---|---|
| ← → | 切换月份 |
| Esc | 关闭弹窗/侧边栏 |

## 部署

推荐使用 [Railway](https://railway.app) 免费部署：

1. 将代码推送到 GitHub
2. 在 Railway 中导入该项目
3. 设置 `PORT` 环境变量（可选）
4. 部署后即可通过公网访问
